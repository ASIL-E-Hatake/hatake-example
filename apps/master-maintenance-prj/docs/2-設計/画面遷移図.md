> **どの画面からどの画面へ行けるか**。箱の中は「誰が開けるか」。

```mermaid
%% 社内マスタ（master_maintenance）の画面と遷移
%% 段は「メニューから開ける画面 → そこから遷移で開く画面」。線は遷移の向き（札はボタン名）。箱の中は誰が開けるか。
flowchart LR
  department_master["部署マスタ<br/>department_master<br/>・ 誰でも開ける"]
  supplier_master["取引先マスタ<br/>supplier_master<br/>・ 誰でも開ける"]
  employee_master["社員マスタ<br/>employee_master<br/>・ 誰でも開ける"]
  employee_detail["社員詳細<br/>employee_detail<br/>・ 誰でも開ける"]
  employee_master -->|詳細| employee_detail
  classDef input fill:#e8f0fe,stroke:#4285f4,color:#202124
  class department_master,supplier_master,employee_master input
  classDef core fill:#e6f4ea,stroke:#34a853,color:#202124
  class employee_detail core
```
