# 工程ごとに何を用意するか（2本目）

紙の3種類と工程の分け方は**1本目と同じ**です
（→ [1本目の docs/README](../../master-maintenance-prj/docs/README.md)）。
ここには**この案件の置き場**だけ書きます。

| 名前の形 | 誰が作るか | 直していいか |
|---|---|---|
| `案件の説明.md` のような普通の名前 | **人** | 人が直す。AI に書かせない |
| `出力-*.txt` | **道具**（そのまま置いただけ） | **手で直さない。** `tools/refresh-docs.sh` で作り直す |
| `2-設計/` の紙 | **道具**（定義から生成） | **手で直さない。** `node tools/build-design-docs.mjs` |
| `definitions/*.yaml` | AI（人の依頼で） | AI が直す。人は読んで判断する |

人が AI に**何を投げたか**は [手順/](../手順/) にあります。
