## 受注入力（order_entry）— 入力をステップに分けた画面

### データ

- データの出どころは orderRepository（アプリ側が用意する）。
- 1件を指すキーは orderNo。

### 入力の順番

- 1. 取引先と納期（6 項目） — まず誰からの注文かを入れてください。受注番号はサーバが採番します。
- 2. 明細（1 項目） — 商品と数量を入れてください。金額は自動で出ます。
- 3. 確認（5 項目） — 金額を確かめて保存してください。保存する値の正はサーバです。

### 取引先と納期の項目

- 取引先 … 選択、必須、選択肢は customerRepository から引く
- 受注日 … 日付、必須
- 納期 … 日付、必須、受注日 以上
- 担当 … 必須、20 文字以内
- 納入先 … 60 文字以内
- 備考 … 複数行、200 文字以内

### 明細の項目

- 明細 … 明細（表で複数行）、必須、商品 が同じ行は書けない、1行は 商品・数量・単価・税率・金額・取消、行はこのレコードと一緒に保存する

### 確認の項目

- 明細 … 明細 の件数（手では入れない）、取消 が true でないときの行だけ
- 小計 … 明細 の 金額 の合計（手では入れない）、取消 が true でないときの行だけ、¥1,234,567 のように見せる
- 消費税 … 他の項目から自動で計算する（手では入れない）、¥1,234,567 のように見せる
- 合計 … 他の項目から自動で計算する（手では入れない）、¥1,234,567 のように見せる
- 商品 … 複数行、読み取り専用、明細 の 商品 を並べたもの（手では入れない）、取消 が true でないときの行だけ、先頭の 5 件だけ（並べ替えなし）、切ったぶんは件数で言う
