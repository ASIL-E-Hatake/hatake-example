## 注文請書（order_slip）— 印刷向けの帳票

### データ

- データの出どころは orderLineRepository（アプリ側が用意する）。

### 絞り込める条件

- 受注番号 … 完全一致
- 受注日 … 期間・範囲（開始と終了の2つ）

### 印刷する列

- 商品コード
- 商品名
- 数量
- 単価（¥1,234,567 のように見せる）
- 税率（12.3% のように見せる）
- 金額（¥1,234,567 のように見せる）

### 帳票の体裁

- 用紙は A4 の縦、1枚に 30 行
- orderNo の昇順で並べて印刷する
- 受注番号（orderNo）が変わるところで小計を出す。変わったら改ページする
- 合計を出すのは amount（合計）、amount（件数）
- 1回に取るのは 200 行まで

### できる操作

- CSV 出力 … 内容をファイルに出す。失敗したら理由がそのまま出る（業務の言葉にするなら onError）。clerk / manager だけに出る
- 印刷 … 紙に刷る。失敗したら理由がそのまま出る（業務の言葉にするなら onError）。clerk / manager だけに出る
