## 受注ダッシュボード（order_dashboard）— 数字とグラフのカードを並べて見せる画面

### データ

- データの出どころは orderRepository（アプリ側が用意する）。

### 絞り込める条件

- 受注日 … 期間・範囲（開始と終了の2つ）
- 受注状態 … いずれかに一致。選べるのは 入力中 / 確定 / 出荷済 / 取消

### 並ぶカード

- 受注件数 … 件数、押すと openOrders を実行
- 受注金額 … 合計（totalAmount）
- 平均受注額 … 平均（totalAmount）
- 取消 … 件数、押すと openOrders を実行
- 取引先別の受注金額 … 棒 のグラフ（customerNameごと）
- 日別の受注金額 … 折れ線 のグラフ（orderDateごと）
- 直近の受注 … 一覧（受注番号・取引先・受注日・受注状態・合計）

### できる操作

- 受注照会 … 別の画面へ移る（order_search へ）

### この画面を開ける人

- 開けるのは … manager だけ
- 入口「ダッシュボード」（メニュー） … manager だけが通れる

### この画面でできないこと

- ここからデータは書き換えられない
