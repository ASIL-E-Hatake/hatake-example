# 画面遷移図

> **この紙は生成物です。** `tools/build-design-docs.mjs` が
> [定義](../../definitions/app.yaml)から起こしています（手で直さない）。
> 定義を直したら `node tools/build-design-docs.mjs` で作り直してください。
>
> **どの画面からどの画面へ行けるか**。箱の中は「誰が開けるか」。

```mermaid
%% 受注管理（order_entry）の画面と遷移
%% 段は「メニューから開ける画面 → そこから遷移で開く画面」。線は遷移の向き（札はボタン名）。箱の中は誰が開けるか。
flowchart LR
  order_entry["受注入力<br/>order_entry<br/>・ 誰でも開ける"]
  order_slip["注文請書<br/>order_slip<br/>・ clerk / manager だけ"]
  order_dashboard["受注ダッシュボード<br/>order_dashboard<br/>・ manager だけ"]
  order_search["受注照会<br/>order_search<br/>・ 誰でも開ける"]
  order_detail["受注詳細<br/>order_detail<br/>・ 誰でも開ける"]
  order_search -->|詳細| order_detail
  classDef input fill:#e8f0fe,stroke:#4285f4,color:#202124
  class order_entry,order_slip,order_dashboard,order_search input
  classDef core fill:#e6f4ea,stroke:#34a853,color:#202124
  class order_detail core
```
