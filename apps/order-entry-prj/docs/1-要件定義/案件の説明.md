# 受注入力（人が最初に書いたメモ）

> **これは人が書いた紙です。** AI に渡す前に、人が知っていることを普通の日本語で
> 書き出しただけのもの。ここを AI に書かせてはいけない。

## どんなシステムか

営業事務が電話・FAX で受けた注文を入れて、出荷指示まで出す画面。
いまは Excel の注文書を手で転記していて、単価の入れ間違いと消費税の計算違いが毎月出る。

利用者は営業所3拠点で15人くらい。繁忙期は1日200件入る。

## 誰が使うか

| 役割 | できること |
|---|---|
| 営業（sales） | 受注を入れる・直す。自分の拠点のぶんだけ |
| 営業事務（clerk） | 全拠点の受注を入れる・直す・取り消す |
| 管理者（manager） | 全部。ダッシュボードと帳票も見る |

ログインは既存の社内ポータルの ID を使う（そちらが役割も返してくれる）。

## 受注入力の画面

1件の受注は「ヘッダ（受注番号・取引先・受注日・納期・担当）」と
「明細（商品・数量・単価・金額）」でできている。明細は1〜20行くらい。

- 受注番号は**サーバが採番**する（画面では触らせない）
- 明細の金額 = 数量 × 単価（**画面で自動計算**。手で入れさせない）
- 小計 = 明細の金額の合計
- 消費税 = 小計 × 税率（標準10%。軽減8%の商品が混ざることがある）
- 合計 = 小計 + 消費税
- 同じ商品を2行に分けて入れてしまうミスが多いので、**重複を弾きたい**
- 納期は受注日以降
- 数量は1以上

## 受注の登録はステップで進めたい

新人が多いので、いきなり全部の欄が出ると迷う。
「取引先を選ぶ → 明細を入れる → 確認して確定」の3ステップにしたい。

## そのほかの画面

- **受注照会**: 受注番号・取引先・受注日の範囲・状態で探す。一覧から詳細へ
- **受注詳細**: 1件を読むだけ（明細も見える）
- **ダッシュボード**: 今月の受注件数・受注金額・取引先別の上位・日別の推移
- **注文請書（帳票）**: 1件を A4 で刷って取引先に送る。明細と合計が出る

## やりたいこと（画面以外も含む）

- 出荷指示は基幹システムに流す（こちらからは投げるだけ）
- 単価は取引先ごとの契約単価を使いたいが、**今回は商品マスタの定価でよい**
- 締めた月の受注は直せないようにしたい
- 取り消した受注も残す（消さない）

## 決まっていないこと

- 締め処理を誰がやるか
- 消費税の端数（切り捨て？　四捨五入？）
- 同時に同じ受注を直したときにどうするか
- 出荷指示を投げるタイミング
