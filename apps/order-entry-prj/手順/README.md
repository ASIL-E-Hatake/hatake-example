## 2本目でいちばん効いたこと

1本目で作った道具（設計資料を起こす・出力紙を作り直す・テストを回す）を
**案件の外に上げた**ので、2本目は**設定ファイル2枚を書くだけ**で同じ紙が出ました。

```
tools/                        ← 案件をまたいで使う（1本目で作ったもの）
├─ build-design-docs.mjs
├─ refresh-docs.sh
├─ run-tests.sh
└─ api-report.mjs

apps/order-entry-prj/tools/   ← 案件ごとに書くのはこれだけ
├─ design.config.json         API の実装がどこか・定義に書けない口は何か
└─ test.config.sh             DB の名前・画面の URL・値の試験を回す画面
```

1本目の生成物が**バイト単位で同じ**であることを確かめてから上げました
（道具を動かして、出てくる紙が変わらないこと＝安全に使い回せること）。
