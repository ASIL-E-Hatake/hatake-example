---

この案件の定義を検収してください。

```bash
npx hatake check definitions/app.yaml --project definitions/hatake.project.yaml
npx hatake ask  definitions/app.yaml --project definitions/hatake.project.yaml
npx hatake refs definitions/app.yaml --needs-registration
bash tools/refresh-docs.sh --check
node tools/build-design-docs.mjs --check
```

出すのはこの4つ:

1. 事実（警告）… **0件でなければ直す**
2. 好み（助言）… 当てるかは人が決める。**勝手に当てない**
3. 人が決めること（問い）… **答えない**。そのまま人に渡す
4. まだ登録していないもの（Repository・プラグイン・出す口）

`--check` が落ちたら、`docs/` の生成物が古い（作り直して commit）。

そのあと **撮った絵も見てください**（テストが全部緑でも、絵を見ないと
分からない種類がある）。
