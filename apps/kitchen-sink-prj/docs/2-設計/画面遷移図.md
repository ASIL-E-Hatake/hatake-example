# 画面遷移図

> **この紙は生成物です。** `tools/build-design-docs.mjs` が
> [定義](../../definitions/app.yaml)から起こしています（手で直さない）。
> 定義を直したら `node tools/build-design-docs.mjs` で作り直してください。
>
> **どの画面からどの画面へ行けるか**。箱の中は「誰が開けるか」。

```mermaid
%% 機能網羅（kitchen_sink）の画面と遷移
%% 段は「メニューから開ける画面 → そこから遷移で開く画面」。線は遷移の向き（札はボタン名）。箱の中は誰が開けるか。
flowchart LR
  combo_form["条件の組み合わせ<br/>combo_form<br/>・ 誰でも開ける"]
  linked_master["選択肢の連動<br/>linked_master<br/>・ 誰でも開ける"]
  steps_wizard["ステップ入力<br/>steps_wizard<br/>・ 誰でも開ける"]
  sorted_report["帳票（降順）<br/>sorted_report<br/>・ 誰でも開ける"]
  press_list["押す前に聞く<br/>press_list<br/>・ 誰でも開ける"]
  fold_detail["畳み込み<br/>fold_detail<br/>・ 誰でも開ける"]
  press_list -->|詳細| fold_detail
  classDef input fill:#e8f0fe,stroke:#4285f4,color:#202124
  class combo_form,linked_master,steps_wizard,sorted_report,press_list input
  classDef core fill:#e6f4ea,stroke:#34a853,color:#202124
  class fold_detail core
```

> 点線の箱は**誰も開けない画面**（入口の権限が食い違っている）、
