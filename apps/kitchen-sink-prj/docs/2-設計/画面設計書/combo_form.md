## 条件の組み合わせ（combo_form）— 1件を入力する画面（新規と編集の両方）

### データ

- データの出どころは itemRepository（アプリ側が用意する）。
- 1件を指すキーは itemCode。

### 元になる値

- コード … 必須
- 種別 … 選択、必須、選べるのは 標準 / 特別 / 試用
- 金額 … 数値、¥1,234,567 のように見せる
- 承認済み … チェックボックス

### 組み合わせで出し分ける

- 特別かつ 1000 超のときだけ … 複数行、種別 が 特別 のとき、かつ 金額 が 1000 より大きいときだけ出る
- 試用か承認済みのときだけ … 複数行、種別 が 試用 のとき、または 承認済み が true のときだけ出る
- 標準でないときだけ … 種別 が 標準 のときの逆だけ出る
- 「特別かつ承認済み」でないときだけ … 種別 が 特別 のとき、かつ 承認済み が true のときの逆だけ出る

### できる操作

- 保存 … アプリ側の処理を呼ぶ（saveItem）。失敗したら理由がそのまま出る（業務の言葉にするなら onError）

### この画面を開ける人

- 開けるのは … 誰でも開ける
- 入口「条件の組み合わせ」（メニュー） … 誰でも通れる

### この画面でできないこと

- 一覧は無い（開く先は呼び出し側が決める）
- 新規登録のボタンは無い（入力画面は他から開く）
