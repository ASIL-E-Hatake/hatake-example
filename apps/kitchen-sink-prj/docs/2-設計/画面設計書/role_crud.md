## 見せる相手で変わる（role_crud）— 検索して一覧に出し、その場で登録・修正・削除までできる画面

### データ

- データの出どころは itemRepository（アプリ側が用意する）。
- 1件を指すキーは itemCode。

### 絞り込める条件

- 名前 … 部分一致

### 一覧に出る列

- コード（並べ替えできる）
- 名前（並べ替えできる）
- 原価（¥1,234,567 のように見せる）
- 5 件ずつページングする

### 誰が直せるか

- コード … 必須、$mode が undefined のときは直せない
- 名前 … 必須
- 原価 … 数値、admin だけに見える
- 覚え書き … 複数行、名前 が入っているときだけ必須

### できる操作

- 保存 … アプリ側の処理を呼ぶ（saveItem）。失敗したら理由がそのまま出る（業務の言葉にするなら onError）
- CSV 出力 … 内容をファイルに出す。失敗したら理由がそのまま出る（業務の言葉にするなら onError）。admin だけに出る

### 行ごとの操作（一覧の各行に出る）

- 編集を開く
- 削除する

### この画面を開ける人

- 開けるのは … 誰でも開ける
- 入口「見せる相手で変わる」（メニュー） … 誰でも通れる

### 画面の中で隠れるもの（権限）

- 列「原価」 … admin だけ
- ボタン「CSV 出力」 … admin だけ
- 項目「原価」 … admin だけ

### この画面でできないこと

- 新規登録のボタンは無い（入力画面は他から開く）
