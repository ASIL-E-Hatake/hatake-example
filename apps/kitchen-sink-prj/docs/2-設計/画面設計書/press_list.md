# 押す前に聞く（press_list）

> **この紙は生成物です。** `tools/build-design-docs.mjs` が
> [定義](../../../definitions/app.yaml)から起こしています（手で直さない）。
> 定義を直したら `node tools/build-design-docs.mjs` で作り直してください。
>
> **この画面が何をするか**を、DSL のキー名を出さずに書いたもの。

- 種別: 照会（検索・一覧）
- データの出どころ: `itemRepository`
- 1件を指すキー: `itemCode`

## 押す前に聞く（press_list）— 検索して一覧を見るだけの画面

### データ

- データの出どころは itemRepository（アプリ側が用意する）。
- 1件を指すキーは itemCode。

### 絞り込める条件

- コード … 前方一致
- 種別 … 完全一致。選べるのは 標準 / 特別 / 試用

### 一覧に出る列

- コード（並べ替えできる）
- 名前（並べ替えできる）
- 種別
- 金額（¥1,234,567 のように見せる、並べ替えできる）
- 20 件ずつページングする

### できる操作

- 詳細 … 別の画面へ移る（fold_detail へ）。別のタブで開く。押せるのは 種別 が 試用 でないとき だけ
- まとめて単価を変える … アプリ側の処理を呼ぶ（reprice）。選んだ行に対して実行する（1回で最大 20 件まで（tester は 10 件）＝定義で決めた上限）。5 件ずつ実行する（進み具合が出て、区切りで止められる）。上限まで選ぶと 4 回に分かれる。区切りは役割で変わる（admin は 8 件）。押すと 単価 / 理由 を聞く。終わったら press_list へ移る。失敗したら「{count} 件が変えられませんでした（失敗した行: {failedKeys}）」と出す。tester / admin だけに出る
- 書庫に入れる … アプリ側の処理を呼ぶ（archive）。選んだ行に対して実行する（1回で最大 20 件まで＝定義で決めた上限）。押すと確認を出す。終わったら「{count} 件を書庫に入れました」と出す。失敗したら「{count} 件が入れられませんでした（失敗した行: {failedKeys}）」と出す。tester / admin だけに出る
- CSV 出力 … 内容をファイルに出す。失敗したら理由がそのまま出る（業務の言葉にするなら onError）。admin だけに出る

### 行ごとの操作（一覧の各行に出る）

- 詳細

### この画面を開ける人

- 開けるのは … 誰でも開ける
- 入口「押す前に聞く」（メニュー） … 誰でも通れる
- 入口「一覧へ戻る」（fold_detail から） … 誰でも通れる
- 入口「やめる」（steps_wizard から） … 誰でも通れる

### 画面の中で隠れるもの（権限）

- ボタン「まとめて単価を変える」 … tester / admin だけ
- ボタン「書庫に入れる」 … tester / admin だけ
- ボタン「CSV 出力」 … admin だけ

### この画面でできないこと

- 登録・修正・削除はできない（照会専用）
