# 見本を 0.9.26 → 0.9.27 に上げた記録

> **中身**: 実際に上げてみて、何が起きて何が起きなかったか。
> **前の回**: [0.9.25 → 0.9.26](移行-0.9.25から0.9.26.md)。
> 枠組み側で何が変わったかは [CHANGELOG](https://github.com/ASIL-E-Hatake/hatake/blob/main/CHANGELOG.md)
> の 0.9.27。

0.9.27 は書き方だけの版です: **手引きと道具の文の `npx hatake …` を `npx -p @hatake-fw/api hatake …` に
直した**。前の回で「枠組みの側に返す」と書いた件で、枠組みは npm に出さないまま、書き方で守る
ことにした。

## なぜ

npm の registry に `hatake` という**別の人の、名前が同じだけの道具**が在る。枠組みは registry に
出していないので、手元に入っていない場所で名前だけの `npx hatake …` を打つと、**それを取ってきて、
こちらの引数で走らせる**。`npx -p @hatake-fw/api hatake …` なら、入れてあれば手元の物を使い、
入っていなければ 404 で止まる（`@hatake-fw` の名前は押さえてあるので、別の人は出せない）。
